The orchestrator prompt generated by `hub generate` is now significantly more complete. Six new sections are injected into every editor's orchestrator output, covering behavior patterns that leading AI coding tools use internally.

## What changed

New shared sections added to all orchestrator prompts (Cursor, Claude Code, OpenCode, Kiro):

- **Core Behavior** — conciseness, accuracy over reassurance, no invented facts, no unnecessary apologies
- **Working Style** — simplest solution, avoid over-engineering, prefer editing over creating, bias toward self-discovery
- **Search, Reading, and Investigation** — read before editing, gather context before answering, lightweight search first
- **Code Changes** — runnable code, preserve patterns, read before modifying, max 3 retry attempts on errors, check dependencies before assuming
- **Security and Safety** — no hardcoded secrets, flag risks, avoid common vulnerability patterns
- **Git and Operational Discipline** — inspect before committing, specific staging, no destructive operations without authorization

These sections are based on analysis of system prompts from Cursor and Claude Code, adapted for multi-repo workspace orchestration.

## Why

The previous orchestrator prompt focused on pipeline mechanics (repos, steps, delivery) but lacked guidance on how the agent should behave when actually working. This led to verbose responses, speculative edits, blind modifications, and unnecessary questions. The new sections encode the behavioral patterns that make AI coding assistants effective.

## Who is affected

All workspaces using RHM. After upgrading, run `hub generate` to regenerate prompts for your editor.
