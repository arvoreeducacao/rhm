Every editor generator now writes `AGENTS.md` at the workspace root, providing a universal orchestrator reference that works across tools. For Kiro, the duplicate `.kiro/steering/orchestrator.md` is no longer generated since `AGENTS.md` already serves the same purpose.

## What changed

- `generateCursor` now writes `AGENTS.md` alongside `.cursor/rules/orchestrator.mdc`
- `generateClaudeCode` now writes `AGENTS.md` alongside `CLAUDE.md`
- `generateOpenCode` now writes `AGENTS.md` alongside `.opencode/agents/orchestrator.md`
- `generateKiro` no longer writes `.kiro/steering/orchestrator.md` — only `AGENTS.md`

## Why

The Kiro steering `orchestrator.md` was identical to `AGENTS.md`, causing the orchestrator instructions to be injected twice into context. Removing the duplicate reduces token usage and avoids conflicting priorities. Making `AGENTS.md` universal means any editor or tool that reads it gets the orchestrator context automatically.

## Who is affected

All workspaces. After upgrading, run `hub generate` to regenerate. If you have a stale `.kiro/steering/orchestrator.md`, you can safely delete it.
